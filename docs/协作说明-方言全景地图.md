# 协作说明：方言全景地图模块

本文档面向与本仓库并行开发其他功能的同学，用于对齐 **接口、数据字段、命名与运行方式**，减少合并冲突与「变量不同步」类问题。

---

## 1. 模块位置与职责

| 路径 | 说明 |
|------|------|
| `src/components/DialectPanoramaMap.vue` | 方言全景地图 **整页**（导航、侧栏、高德地图、右侧详情、录音上传、悬浮按钮） |
| `src/App.vue` | 当前仅挂载上述组件；若你引入 Vue Router，建议将地图页改为独立路由页面，并把顶栏/侧栏是否抽离与团队约定 |
| `vite.config.js` | 开发服内置 **Mock**：`/api/map/points`、`/api/map/upload`；接真实后端时需删除或改写 Mock，并配置 `proxy` |

地图页 **未使用** Pinia / Vuex；状态均在单文件组件内。若全局 store 中已有 `map`、`points`、`region` 等命名，请注意与下文 **API 字段名** 区分，避免同名不同义。

## 2. 后端接口约定（请与后端/联调文档保持一致）

### 2.1 获取地图点位

- **方法 / 路径**：`GET /api/map/points`
- **响应体（建议）**：

```json
{
  "code": 0,
  "data": [
    {
      "id": "string",
      "location": { "lng": 120.15, "lat": 30.28 },
      "area": "浙江省/杭州市/西湖区",
      "dialect": "吴语·杭州小片",
      "type": "方言",
      "audioUrl": "https://...",
      "content": "文字内容",
      "nickname": "发言人昵称",
      "time": "2026-04-10 14:22:00"
    }
  ]
}
```

- **字段语义（请勿擅自改名，除非全栈同步修改）**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 点位唯一标识 |
| `location.lng` / `location.lat` | number | 高德坐标（GCJ-02） |
| `area` | string | 地区展示与筛选；格式约定为 **`省/市/区县`**，与侧栏三级联动选项拼接结果一致 |
| `dialect` | string | 方言片区 / 类型描述（展示在详情卡） |
| `type` | string | 内容类型，取值仅限：`方言`、`戏曲`、`民谣`、`童谣`、`民俗`（与前端多选筛选项一致） |
| `audioUrl` | string | 可直链播放的音频地址 |
| `content` | string | 文字内容 |
| `nickname` | string | 发言人昵称 |
| `time` | string | 上传时间（展示用字符串即可） |

前端筛选逻辑依赖：`area` 与 `省/市/区` 字符串前缀或全等匹配；`type` 与多选数组包含关系。

### 2.2 上传方言录音

- **方法 / 路径**：`POST /api/map/upload`
- **Content-Type**：`multipart/form-data`
- **表单字段（当前前端已发送）**：

| 字段名 | 说明 |
|--------|------|
| `file` | 录音文件（Blob 转 File；扩展名随 MIME，常见 `.webm`） |
| `area` | 完整地区字符串，格式 **`省/市/区县`** |
| `dialect` | 方言类型 / 片区（文本） |
| `type` | 内容类型，上述五选一 |
| `content` | 文字说明（可选，可为空字符串） |

- **成功响应（建议）**：`{ "code": 0, "message": "ok", "data": { "id": "..." } }`  
  前端以 `code === 0` 且 HTTP 2xx 视为成功，成功后 **会再次请求** `GET /api/map/points` 刷新标记。

若你方接口路径、字段名或响应结构与上表不同，请 **同时改** `DialectPanoramaMap.vue` 中的 `fetch` / `FormData.append` 与类型说明，并在 PR 描述里写明。

## 3. 前端常量与命名（易冲突点）

以下内容写在 `DialectPanoramaMap.vue` 内，若你在其他模块使用同名全局或 export，请注意区分：

| 名称 | 含义 |
|------|------|
| `AMAP_KEY` | 高德 Key；生产建议改为环境变量（如 `import.meta.env.VITE_AMAP_KEY`），勿把个人/生产 Key 长期硬编码在仓库 |
| `contentTypes` | 固定数组：`['方言','戏曲','民谣','童谣','民俗']` |
| `regionTree` | 侧栏与上传表单共用的 **示例** 省市区树；若你接入完整行政区划 JSON，建议抽到 `src/data/regions.js` 并双方 import 同一份数据源 |
| `allPoints` | 接口返回的原始点位列表 |
| `filteredPoints` | 根据省市区 + 类型多选计算后的列表 |
| `selProvince` / `selCity` / `selDistrict` | 侧栏筛选用 |
| `uploadProvince` / `uploadCity` / `uploadDistrict` | 上传弹窗用（可与侧栏同步，但 ref 独立） |

录音相关：`recordBlob`、`previewUrl`、`mediaRecorder` 等仅在地图组件内使用，一般不与全局冲突。

## 4. 高德地图与安全配置

- 脚本加载地址形如：`https://webapi.amap.com/maps?v=2.0&key=...&plugin=AMap.Scale,AMap.ToolBar,AMap.Geolocation&callback=...`
- 若高德控制台要求 **安全密钥**，需在加载脚本前设置（具体以高德文档为准），例如：

```js
window._AMapSecurityConfig = { securityJsCode: '你的安全密钥' }
```

与负责部署的同学对齐：Key / 安全密钥 **不要** 提交到公开仓库时，用 `.env` + `.gitignore`。

## 5. 本地运行与 Mock

```bash
npm install
npm run dev
```

- 开发环境下点位与上传由 `vite.config.js` 中插件 Mock，便于无后端联调。
- **`npm run build` 后的静态资源不包含该 Mock**，预览/生产需真实后端或网关转发 `/api`。

---

## 6. 合并代码时的建议

1. **接口字段**：以后端/本文档 2.1、2.2 为准；变更时在群或 PR 里 @ 地图页维护者。  
2. **地区数据**：若你改为远程加载行政区划，请保留与 `area` 相同的拼接规则（`省/市/区县`）。  
3. **路由**：引入 `vue-router` 后，将 `DialectPanoramaMap` 注册为独立路由（如 `/map`），首页路由勿与地图页全局样式（如 `body { overflow: hidden }`）冲突。  
4. **全局样式**：地图页依赖全屏高度（`html, body, #app { height: 100% }` 在 `src/style.css`）；你新增的全局 `overflow` / `height` 可能影响地图，合并时注意。
